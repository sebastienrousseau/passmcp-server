## Highlights ⭐️

* **Evaluate an MCP server from inside the agent**: passmcp-server exposes passmcp's diagnostics as MCP tools, so an agent can check a server, or verify an attestation about one, without leaving the editor.
* **Read-only and allowlisted**: the tools never change a target, only reach the servers you allow, and send no credential.
* **Install or run it**: release archives for Linux, macOS and Windows, and the image `ghcr.io/sebastienrousseau/passmcp-server:0.0.1`, built on passmcp 0.0.1's signed image.
