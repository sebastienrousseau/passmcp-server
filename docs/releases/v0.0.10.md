## Highlights ⭐️

* **In lockstep with passmcp 0.0.10**: the image builds on `ghcr.io/sebastienrousseau/passmcp@sha256:161d1d5773ecb768db95e14f8e70cce4cf58a84b8a723db16da11d629cf15fe1`, and every install line, container tag, `server.json`, and `glama.json` registry listing names `0.0.10`.
* **Attestations verified by passmcp-reporting 0.0.10**: `go.mod` requires `satellion.com/passmcp-reporting v0.0.10`; its verifier packages are unchanged from `0.0.9`, so `passmcp_verify_attestation` answers identically.
* **15-repository lockstep family table**: `README.md` lists all six Apache-2.0 MCP language SDKs (`passmcp-sdk-go`, `passmcp-sdk-python`, `passmcp-sdk-java`, `passmcp-sdk-cpp`, `passmcp-sdk-typescript`, and `passmcp-sdk-rust`) alongside the existing nine family repositories.
