## Highlights ⭐️

* **The same three tools**: `passmcp_check`, `passmcp_verify_attestation` and `passmcp_version` take the arguments and return the results they did in 0.0.1. This release carries the family's version and runs on passmcp 0.0.2.
* **Install from source with `make install`**: The binary and its bash, zsh and fish completions install under `PREFIX`, staged under `DESTDIR` for packagers, and `make uninstall` removes them.
* **Every version pin is checked**: The release check now covers the install lines, `CITATION.cff` and the passmcp-reporting release `go.mod` requires, and fails if it finds no install line at all.
