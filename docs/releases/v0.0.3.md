## Highlights ⭐️

* **The same three tools**: `passmcp_check`, `passmcp_verify_attestation` and `passmcp_version` take the arguments and return the results they did in 0.0.2. This release carries the family's version and runs on passmcp 0.0.3.
* **Fuzzed where input arrives**: Fuzz targets now drive the stdio loop and the endpoint allowlist with arbitrary input, and check that nothing but JSON-RPC reaches stdout and that passmcp is never sent to an endpoint the allowlist refuses.
* **A publishing guide that works**: The registry guide now describes the DNS proof that the `com.sebastienrousseau` namespace needs, instead of a GitHub login that cannot publish it.
